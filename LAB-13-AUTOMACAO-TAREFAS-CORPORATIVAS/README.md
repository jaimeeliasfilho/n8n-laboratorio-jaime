LAB 13 — RPA e Automação de Tarefas Corporativas com Python e Playwright

Objetivo

Desenvolver uma automação robótica de processos (RPA) para executar tarefas repetitivas em uma aplicação web simulada, utilizando Python, Pandas e Playwright.

O projeto demonstra como um robô pode processar solicitações, interagir com elementos de uma interface web, preencher formulários automaticamente e registrar os resultados da execução.

Tecnologias utilizadas

- Python
- Google Colab
- Pandas
- Playwright
- Chromium
- OpenPyXL
- Microsoft Excel

Etapas desenvolvidas

1. Criação de uma base de solicitações corporativas.
2. Identificação e filtragem de tarefas pendentes.
3. Organização das solicitações em uma fila de execução.
4. Configuração do ambiente de automação com Playwright.
5. Abertura e identificação de elementos de uma aplicação web.
6. Preenchimento automatizado de formulários.
7. Acionamento de botões e captura de mensagens de confirmação.
8. Processamento sequencial de múltiplas solicitações.
9. Consolidação dos resultados em um relatório Excel.

Arquivos do projeto

Competências demonstradas

- Automação de tarefas com Python.
- RPA aplicado a interfaces web.
- Manipulação e preparação de dados.
- Automação de formulários.
- Processamento de filas de tarefas.
- Captura e validação de resultados.
- Geração de relatórios operacionais.

Observação técnica

A aplicação utilizada foi construída para fins de demonstração e treinamento. O projeto demonstra automação de navegador com Playwright, não integração com um sistema corporativo real.

O laboratório apresenta fundamentos de RPA aplicáveis a processos administrativos e operacionais, sem representar certificação ou domínio de plataformas comerciais específicas como UiPath ou Power Automate Desktop.

Finalidade

Projeto educacional e demonstrativo desenvolvido para compor portfólio profissional na área de Automação de Processos, RPA e Integração de Sistemas.
