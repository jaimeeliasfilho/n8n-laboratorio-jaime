LAB 01 — Tadeu Rechilieu | Automação de Pedidos e Atendimento

📌 Sobre o projeto

Automação desenvolvida com n8n para organizar solicitações de clientes de um pequeno negócio, facilitando o direcionamento de pedidos de orçamento, consultas de prazo e informações sobre pagamento.

🎯 Objetivo

Reduzir tarefas manuais, padronizar o recebimento das solicitações e melhorar a organização do atendimento.

⚙️ Funcionamento

1. O cliente preenche um formulário de solicitação.
2. O workflow recebe os dados informados.
3. Os campos são tratados e normalizados.
4. Um nó Switch identifica o tipo de solicitação.
5. A automação direciona cada solicitação para a saída correspondente:
   - Orçamento
   - Prazo
   - Pagamento

🛠️ Tecnologias utilizadas

- n8n
- Form Trigger
- Edit Fields
- Switch
- Expressões JavaScript
- JSON

💡 Aprendizados

- Construção de workflows no n8n.
- Recebimento e tratamento de dados.
- Normalização de textos e campos.
- Uso de condições para direcionamento de fluxos.
- Organização de processos de atendimento.

📈 Resultado

Workflow funcional para estruturar e direcionar solicitações de clientes, demonstrando na prática como a automação pode contribuir para a eficiência operacional de pequenos negócios.
